# Positron

## What is Positron?

Positron is a data science IDE built for Python and R, and it provides
more streamlined deployment options and deeper integration with both R
and Python environments. It will look familiar to both users of R Studio
and Visual Studio Code, but it provides more interactive features for
examining variables, datasets and plots.

It further allows users to work with tools such as Shiny and Quarto, and
to publish work directly to Posit Connect and Posit Connect Cloud within
the same application.

Compared to RStudio, the IDE is more customisable and more extensions
are provided.

## Do I need to stop using RStudio?

**No. RStudio and Positron can be used alongside each other.**

You can choose whichever is most appropriate for the work you are doing.
RStudio remains actively supported and there is currently no timeline
for it to be deprecated.

-   Positron may be preferable if you regularly work across R and Python
    *in the same project*, want to run multiple R/Python sessions, or
    want greater customisation through extensions.
    
## Why might I use it instead of RStudio?

-   Easy access to multiple R versions and multiple concurrent R and
    Python interpreters.

-   Data science workflows in R and Python, both as 'first-class'
    languages.

-   Support for other languages beyond R and Python via built-in
    language intelligence or extensions.

-   An integrated Data Explorer for dataframes in your active sessions
    and for a variety of files types (CSV, Parquet, etc.).

-   Extensibility via a large marketplace of 3rd party extensions.

## How much memory does Positron need in Posit Workbench?

Positron typically requires more memory than RStudio, particularly when using multiple 
interpreters or extensions. It is recommended to use at least **4 GB** for a basic or simple
project.

## What replaces RStudio Projects?

**RStudio: Project -\> Positron: Workspace (Folder)**

Positron doesn't use .Rproj files. Instead, you open the project folder
itself as a workspace. In Positron, a workspace is simply a folder
opened in its own window and is used as the project's working directory,
so it is important to open the correct project folder before running
scripts.

Existing .Rproj files can remain in the folder, particularly if you
still use the project in RStudio.

Positron can also create and manage project-specific package
environments using renv for R and venv for Python, with pip or the
faster uv package manager for managing Python packages."

To create a new workspace, go to New -\> New Folder from Template, where
you can select from folder types including Python, R, Jupyter and Empty.

## Do RStudio shortcuts still work?

**Many familiar RStudio shortcuts, including Ctrl + Enter, still work in
Positron by default.**
Helpfully, you can also now use Ctrl + Enter to run Python code chunks.

You can also enable a fuller set of RStudio-style shortcuts:

-   Open the Command Palette (Ctrl + Shift + P).
-   Search for 'Preferences: Open Settings (UI)'.
-   Go to the Remote tab in Settings
-   Search the settings for rstudioKeybindings.
-   Turn it on and reload Positron by typing 'Developer: Reload Window'
    in the Command Palette.
